# Glossary

## Node
An entity in the network. Can be a person, project, or organization.

## Person
An individual who participates in projects or organizations.

## Project
A bounded instance of work with defined participants.

## Organization
An ongoing entity that contains members and may produce projects.

## Role
The function a person has within a project or organization (e.g. editor, contributor, member).

## Edge
A connection between two nodes, defined by participation and roles.

## Trace
A path between two people through shared projects and organizations.

## Ghost node
A person who has been added to the network but has not yet claimed their node.

## Claiming
The process of confirming identity and activating a node in the network.

## Shared work
A project or organization that connects multiple people through participation.
